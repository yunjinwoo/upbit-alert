⭐ 관심종목등록 상위 페이지 안내
📌 목적

얼마나 많은 투자자가 그 종목을 관심종목으로 등록했는지 기준의 랭킹입니다. 네이버 증권 "인기검색종목"과 비슷한 성격의 "관심도" 지표인데, 그 페이지는 robots.txt로 크롤링이 막혀 있어(User-agent: *, Disallow: /) 대신 KIS 공식 API로 대체했습니다.

🔌 사용 API
KIS FHPST01800000

국내주식 관심종목등록 상위 — 한 번의 호출로 이름/가격/등락률/등록건수까지 전부 내려옴 (HTS조회상위처럼 종목별 추가 조회 불필요)

⏱ 수집 주기

자동: 평일 16시(장마감 후) 하루 1회
수동: 즉시 수집 버튼

💡 활용 팁
최대 30종목까지만 제공됨 (KIS API 자체 한계, 페이지네이션 시도했으나 31위 이상은 응답 없음)
정렬 기준은 "최신 등록건수" 내림차순 — 실제 등록 인원 수치라 순위보다 격차를 정량적으로 볼 수 있음
날짜 열은 그날의 실제 순위(1~30위), 등록건수/현재가/등락률은 선택 구간 중 가장 최근 값
"구간 내 있었지만 최근 날짜엔 빠진 종목만 보기"를 켜면 관심권에서 멀어진 종목만 표시됨
⚠️ 한계
하루 1회 수집이라 일중 변화는 보이지 않음 (HTS조회상위와 달리 시간대별 데이터 없음)
