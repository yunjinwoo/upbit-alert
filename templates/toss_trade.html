실거래 승인 종목 현재가 보유수량 평단가 평가금액 평가손익 상태 물타기
로딩 중...
* 실거래 승인 체크박스를 켠 종목만 매매 대상입니다 — 하나도 안 켰으면 스위치를 켜도 아무 것도 사지 않습니다(안전 기본값). 보유 중이면 실제 잔고(수량/평단/평가손익)를, 아직 미보유면 "미보유(매수판단 대상)"으로 표시됩니다. 매매 기준(포지션당 매수금액/손절·익절 등)은 아래 "⚙️ 매매 기준 설정"을 그대로 씁니다.
* 실거래 실행 스위치가 켜져 있어야 python main.py toss_live_trade 프로세스가 다음 사이클에 실주문을 냅니다(기본값 꺼짐). 프로세스 자체를 켜고 끄는 스위치가 아니라, 이미 떠 있는 프로세스가 판단/체결을 실행할지 건너뛸지를 결정합니다.
* 실거래 매매 이력은 📜 매매 이력 페이지에서 "구분"을 🔴 실거래로 바꿔 조회할 수 있습니다.
* 국내 주식은 정수 주(株) 단위로만 주문됩니다(코인처럼 소수점 매수 불가) — 1종목당 매수금액으로 최소 1주도 못 사면 매수를 건너뜁니다.

* 저장하면 DB에 즉시 반영되고, python main.py toss_trade 프로세스가 재시작 없이 다음 사이클부터 새 값을 적용합니다(루프 주기 자체도 다음 사이클부터 바뀐 값으로 동작). 이미 보유 중인 포지션의 손절/익절 판단에도 다음 사이클부터 새 기준이 적용됩니다. (업비트 자동매매와 설정이 완전히 분리돼 있어 여기서 바꿔도 업비트 쪽에는 영향이 없습니다.)
* 손절 기준은 진입가가 아니라 "보유 중 최고가" 대비 하락률(트레일링)입니다. 손절 연속확인 사이클수는 그 조건이 몇 번 연속으로 유지돼야 실제 매도할지(1=즉시, 한 캔들 노이즈로 바로 잘리는 걸 완화하려면 2 이상). 물타기 트리거(%)는 물타기 체크된 포지션이 손절 조건까지 충족된 뒤에도, 평단 대비 이 %까지는 매도 대신 대기했다가 도달 시 1종목당 매수금액만큼 추가매수하는 기준이고, 물타기 최대 횟수는 포지션당 이 추가매수를 몇 번까지 반복 허용할지입니다 — 아래 "보유 포지션" 표에서 종목별로 켤 수 있습니다.
🧪 정밀 매수조건 (다중 시간대, 선택) ▾
사용 조건 결합 파라미터
로딩 중...
* 이 조건들은 기존 진입 후보(stock_screening_daily, 일봉 돌파/구름/200선) 필터 위에 추가로 얹는 필터입니다 — 아래 "매매 대상 종목" 표에서 정밀검사 체크박스를 켠 종목에만 적용되고, 안 켠 종목은 기존과 동일하게(추가 제약 없이) 판단합니다.
* 결합: "필수(AND)"로 켠 조건은 전부 충족해야 하고, "택일(OR)"로 켠 조건은 그중 하나만 충족해도 통과합니다 — 최종 판정 = (필수 조건 전부 통과) AND (택일 조건이 없거나 그중 하나 이상 통과). 켠 조건이 하나도 없으면 정밀검사는 항상 통과로 취급합니다.
* 실시간성이 필요해서 별도 프로세스(python main.py toss_condition_check)가 독립 주기(위 "매매 기준 설정"의 정밀조건 검사 주기, 기본 60초)로 정밀검사 체크된 종목만 일봉/5분봉/1분봉을 다시 조회해 판단하고 결과를 캐시합니다 — 이 프로세스가 안 떠 있으면 정밀검사 켠 종목은 "검사 결과 없음"으로 매수가 보류됩니다. (토스는 5분봉을 직접 제공하지 않아 1분봉을 리샘플링해서 계산합니다.)
📊 스크리닝 근거 조건 (일봉 — 진입 후보 추출 기준) ▾
로딩 중...
* 아래 "매매 대상 종목(진입 후보)" 목록은 stock_screening_daily(일봉, python main.py toss_analysis가 30분 주기로 갱신)에서 이 두 조건 중 하나라도 만족하는 종목만 뽑힙니다 — ①돌파(breakout_1d) 또는 ②200선 근접(near_ma200) AND 구름 위(above_cloud)(둘 다 만족해야). 각 종목이 어느 조건으로 뽑혔는지는 아래 표의 "근거" 열을 펼쳐서 확인할 수 있습니다.
* 스크리닝 대상 종목(유니버스)은 전체 KRX가 아니라 시가총액 상위 Config.TOSS_SCREENING_UNIVERSE_SIZE종목(기존 시가총액 랭킹 재사용)입니다.
* 이 임계값들은 app/core/toss_market_analysis.py 고정값이라 대시보드에서 수정할 수 없습니다(바꾸려면 코드 수정 후 python main.py toss_analysis 프로세스 재시작 필요).

로딩 중...
* 상태는 다음 사이클에 실제로 어떤 판단이 내려질지 미리 계산해 보여주는 값입니다(지금 당장 실행되는 건 아님). 🟡 손절 대기중 = 트레일링 손절 조건은 충족했지만 연속확인 사이클이 안 채워짐 / 🔵 물타기 대기중 = 연속확인은 끝났지만 물타기 트리거(%)까지 대기 중 / 🟣 물타기 완료 = 이미 1회 추가매수해서 평단이 조정됨(더는 물타기 안 함, 이후엔 일반 손절 적용). 물타기 체크박스를 켜면 손절 직전에 곧바로 팔지 않고 한 번 추가매수를 기다립니다 — 자세한 내용은 상단 "매매 기준 설정" 안내 참고.
🎯 매매 대상 종목 (진입 후보, 모의매매) 선택 매매 모드
매매 승인 정밀검사 종목 스크리닝 시점가 등락률(전일대비) 거래대금 근거 보유 여부 스크리닝 갱신시각
로딩 중...
* stock_screening_daily 스냅샷 기준 진입 후보 목록이며, 거래대금 내림차순으로 정렬됩니다(다음 사이클에 실제로 판단할 대상·순서와 동일). 가격·거래대금은 최근 스크리닝 시점 값(최대 30분 전)이며 실시간 시세가 아닙니다. "이미 보유" 종목은 재매수하지 않고 건너뜁니다. 종목명을 클릭하면 토스증권 거래 화면으로 이동합니다.
* 매매 승인 체크박스: 하나 이상 체크하면 다음 사이클부터 체크한 종목만 신규 매수 대상이 됩니다 (이미 보유 중인 종목의 손절/익절 청산에는 영향 없음). 전부 체크 해제하면 다시 전체 후보를 대상으로 합니다.
* 정밀검사 체크박스: 켜면 위 "정밀 매수조건"에서 켠 조건들을 이 종목에도 추가로 요구합니다(만족해야 매수). 체크 직후엔 아직 검사 전이라 "검사 대기"로 표시되고, python main.py toss_condition_check 프로세스가 다음 검사 주기에 결과를 채웁니다.
🎯 매매 대상 종목 (관심 등록 — 1단계, 실거래용)
관심 등록 종목 스크리닝 시점가 등락률(전일대비) 거래대금 근거 보유손익 스크리닝 갱신시각
로딩 중...
* stock_screening_daily 스냅샷 기준 전체 후보 목록이며, 거래대금 내림차순으로 정렬됩니다. 가격·거래대금은 최근 스크리닝 시점 값(최대 30분 전)이며 실시간 시세가 아닙니다. 종목명을 클릭하면 토스증권 거래 화면으로 이동합니다.
* 관심 등록 체크박스: 여기서 켜야만 그 종목이 위 "🔴 실거래" 표(2단계)에 나타나고, 거기서 실거래 승인을 추가로 켜야 실제 매수 대상이 됩니다(이중 안전장치, 모의매매의 "매매 승인"과는 완전히 별개입니다). 이미 매수해 보유 중인 종목은 관심 등록을 나중에 꺼도 손절/익절 관리는 계속됩니다.
* 위쪽 "🔴 실거래" 표만 진짜 계좌에 실제 주문을 낼 수 있습니다(실거래 실행 스위치 + 실거래 승인 둘 다 켜야 함, 기본값 둘 다 꺼짐). 그 아래 "📦 보유 포지션 (가상)"/"🎯 매매 대상 종목 (진입 후보, 모의매매)" 두 표는 지금까지와 동일하게 DB 가상 원장 시뮬레이션일 뿐 실주문이 나가지 않습니다.
* 모의매매 판단/체결은 별도 프로세스(python main.py toss_trade)가, 실거래 판단/체결은 python main.py toss_live_trade가 각자 독립적으로(둘 다 안 떠 있으면 둘 다 자동 실행 안 됨) 주기적으로 실행하며, 이 페이지에서는 즉시 매매를 트리거할 수 없습니다(강제 매수/지금 즉시 실행 버튼 제외).
* 매매 판단/체결 이력(BUY/SELL/HOLD/SKIP 전부, 모의매매·실거래 둘 다)은 📜 매매 이력 페이지에서 "구분"을 바꿔가며 조회할 수 있습니다.
