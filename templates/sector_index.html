코스피/코스닥 종합지수뿐 아니라 화학·전기전자·건설 등 실제 세부 업종별 지수를 일별로 조회하여 섹터 흐름을 파악합니다.

🔌 사용 API
KIS FHPUP02120000

국내주식업종기간별시세(일/주/월/년) — 업종 상세코드로 세부 업종까지 조회 가능. 세부 업종 코드 목록은 국내업종 구분별전체시세(FHPUP02140000)로 확인함.

⏱ 수집 방식

평일 14시/19시 자동 수집(전체 업종) — DB 캐시 조회가 기본, 최신 데이터가 필요하면 "API 조회"로 실시간 호출

💡 활용 팁
