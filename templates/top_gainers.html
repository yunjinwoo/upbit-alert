📈 상승률 순위 페이지 안내
📌 목적

전일 대비 등락률 기준 상승률(또는 하락률) 상위 종목을 실시간으로 조회합니다.

🔌 사용 API
KIS FHPST01700000

국내주식 등락률 순위 — 시장 구분(전체/코스피/코스닥) + 정렬(상승률순/하락률순/시가대비상승률순/시가대비하락률순/변동률순) 선택 가능

⏱ 수집 방식

실시간 탭: DB 저장 없이 조회할 때마다 KIS API를 즉시 호출 (새로고침 시 최신값)
이력 탭: 평일 9:10/12:10/15:10/18:10 자동으로 전체시장 상승률순 스냅샷을 DB에 저장 (일 4회, 정시가 아닌 10분에 실행)
구간 추이 탭: 저장된 스냅샷을 날짜 범위로 모아 종목별 등장 이력을 매트릭스로 확인 (하루 4번 중 그날 최고 순위 1건으로 집계)

🔎 구간 추이의 관심도 표시

같은 날짜에 👀 HTS조회상위20종목 또는 ⭐ 관심종목등록 상위에도 함께 포착된 종목은 순위 배지 옆에 아이콘이 붙습니다. 상승률만으로는 못 거르는 "실제로 관심이 몰린" 종목을 구분하는 용도이며, 오른쪽 요약 열(👀HTS일수/⭐관심등록일수)로 구간 전체 빈도도 볼 수 있습니다.

⚠️ 한계
KIS API가 1회 호출당 30건으로 하드캡되어 있고 연속조회(다음 페이지)도 지원하지 않습니다. "전체"는 코스피+코스닥을 각각 조회해 합쳐서 최대 60건까지 제공하고, 코스피/코스닥 단독 선택 시엔 최대 30건입니다.
등락률(상승률순/하락률순) 기준 재정렬은 전체시장 조회 시 순서가 뒤섞이는 KIS API 버그를 보정한 것이며, 시가대비/변동률 기준은 API가 내려준 순서를 그대로 사용합니다.
이력 스냅샷은 전체시장·상승률순 기준으로만 저장되며, 시장/정렬 필터는 실시간 탭에서만 동작합니다.
