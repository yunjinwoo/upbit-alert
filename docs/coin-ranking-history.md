# 코인 당일 순위 이력 (최근 15일)

> 코드: `app/core/upbit_ranking.py`(저장·집계) · 프로세스 `coin-ranking-bot` (`python main.py coin_ranking`)
> 화면: `/coin-ranking` 아래 "🗓 최근 15일 상위 10 이력" · API `GET /api/coin-ranking/history?kind=gainers|trade_value&top=10`

## 왜

`/coin-ranking`은 업비트 현재가 API를 "지금" 한 번 부르고 끝이라, 어제·그제 누가 상위였는지는 남지 않았다.
상위 목록은 종목이 계속 들고 나기 때문에 "날짜별 상위 10 목록"을 쌓아 두기만 하면 비교가 어렵다 — 종목을
행으로, 날짜를 열로 놓고 "며칠 들어왔는지 / 마감에도 남았는지 / 장중에만 잠깐 들어왔는지"를 보는 게 목적.

## 저장

- 매시 **55분**(`RANKING_HISTORY_MINUTE`)에 상승률 상위·거래대금 상위를 **20위까지**(`RANKING_HISTORY_TOP`) 저장.
  10위 경계를 들락날락하는 종목도 보이도록 표시(10)보다 넉넉하게 저장한다.
- 업비트 등락률·거래대금은 KST 0시에 초기화되므로 **23시 55분 스냅샷이 그날의 마감 순위**다.
- 테이블 `coin_ranking_history(date, hour, kind, rank, ticker, price, change_rate, trade_value, captured_at)`.
  하루 최대 24 × 40 = 960행, 15일이면 약 1.4만 행.
- 스냅샷을 찍을 때마다 **15일**(`RANKING_HISTORY_KEEP_DAYS`)보다 오래된 날짜를 지운다.
- 과거 이력은 되살릴 수 없다(업비트 API가 현재값만 준다) — 배포한 시점부터 쌓인다.
- 프로세스가 꺼져 있던 시간대는 비고, 55분 이후에 켜지면 그 시의 스냅샷을 바로 찍는다.

## 화면

- 숫자 = 그날 마감 순위(오늘은 가장 최근 스냅샷 기준, 머리글에 "HH시까지"), 진한 색일수록 상위.
- `장중` = 장중엔 10위 안에 들었다가 마감 때는 빠진 날. 칸에 마우스를 올리면 몇 시간 들었는지·최고 순위.
- `마감/장중` = 15일 중 마감에 10위 안이었던 날 수 / 장중 한 번이라도 든 날 수. 이 순서로 정렬.
- `NOW` = 가장 최근 스냅샷에도 10위 안.
