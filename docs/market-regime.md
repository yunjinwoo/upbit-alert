# 시장 판단 (좋음 / 애매 / 나쁨)

> 상태: ✅ 구현 완료 · 판단은 **표시와 슬랙 알림 전용** · 전략 묶음은 사람이 눌러서 적용 (2026-09-24)
> 코드: `app/core/market_regime.py` · 프로세스 `market-regime-bot` (`python main.py market_regime`)
> 화면: `/auto-trade` > 📈 시장 지표 카드 맨 위 "시장 판단"

## 왜 만들었나

시장 분위기에 따라 매매 전략을 바꿔 쓰고 싶다는 요청에서 시작했다.

- 좋음 → 손절 여유 · 수익 길게 (`docs/auto-trade-tight-stop.md`)
- 나쁨 → 빠른 손절 · 빠른 익절
- 애매 → 당일 상승률 · 거래대금 위주

전략 자동 전환도 검토했지만 **전략은 사람이 직접 고르기로 했다.** 그래서 이 기능은 "지금 시장이 어떻게
보이는지"를 근거와 함께 보여주고, **판단이 바뀔 때 슬랙으로 알리는 것까지만** 한다. 매매 루프는 이 판단을
전혀 보지 않고, 매매 설정도 바꾸지 않는다.

## 판정 기준

네 항목을 각각 +1 / 0 / -1로 매겨 더한다.

| 항목 | +1 | -1 | 출처 |
|---|---|---|---|
| BTC 추세 | 일봉 현재가 > 20일선 | 일봉 현재가 < 20일선 | 업비트 KRW-BTC 일봉(오늘 봉 포함 20개 평균) |
| BTC 일봉 RSI(14) | ≥ 55 | ≤ 45 | 시장 지표 카드와 같은 값 |
| BTC 4시간봉 RSI(14) | ≥ 55 | ≤ 45 | 시장 지표 카드와 같은 값 |
| 상승 종목 비율 | ≥ 60% | ≤ 40% | 업비트 원화마켓 전 종목 중 전일 대비 오른 종목 비율(`/v1/ticker/all`) |

- 합이 **+2 이상 → 좋음**, **-2 이하 → 나쁨**, 그 사이 → **애매**
- **급락**: BTC가 전일 대비 -5% 이상 빠지면 점수와 무관하게 나쁨
- 값이 있는 항목이 3개 미만이면(조회 장애) 이번 판정은 **보류** — 장애 때문에 애매로 잘못 바뀌지 않게

기준값은 전부 `app/config.py`의 `MARKET_REGIME_*`에 있다.

### 깜빡임 방지

30분마다 판정하고, **같은 새 판정이 2번 연속**(약 1시간) 나와야 바뀐 것으로 본다. 한 번만 다르게 나왔다가
원래대로 돌아오면 아무 일도 없다. 급락으로 나쁨이 된 경우만 기다리지 않고 바로 바꾼다.
화면에는 전환 대기 중인 판정이 "🟡 애매 쪽으로 1/2회"처럼 보인다.

### 도미넌스를 안 쓰는 이유

CoinGecko에서 현재값만 받아서 오르는 중인지 내리는 중인지 알 수 없다. "도미넌스 상승 + BTC 하락 = 알트
약세" 같은 규칙은 이력이 쌓여야 쓸 수 있어서 이번에는 뺐다.

## 슬랙 알림

확정 판단이 바뀔 때만 한 번 보낸다(같은 판정이 이어지는 동안은 조용하다). 처음 실행될 때는 "시장 판단
시작" 알림이 한 번 간다.

```
📊 시장 판단 변경: 🟢 좋음 → 🔴 *나쁨* (점수 -3)
• BTC 20일선: 현재가가 20일선 아래 (-2.10%) (-1)
• BTC 일봉 RSI: 42.3 (-1)
• BTC 4시간봉 RSI: 38.9 (-1)
• 상승 종목 비율: 45% (0)
참고 전략: 빠른 손절 · 빠른 익절 (자동 적용 안 함)
```

## 저장

- `market_regime_state` — 1행. 확정 국면, 확정 시각, 전환 대기 중인 국면과 횟수, 마지막 판정 결과(JSON)
- `market_regime_history` — 확정 국면이 바뀔 때마다 1행(알림과 같은 내용)

대시보드는 이 값을 읽기만 한다. 슬랙과 화면이 같은 판정을 보여주도록 화면에서 다시 계산하지 않는다.
판정이 판정 주기의 3배 넘게 멈춰 있으면 카드에 "판정이 오래 멈춰 있습니다"가 뜬다.

## 전략 묶음 (사람이 골라서 적용)

> 코드: `app/core/strategy_presets.py` · 화면: `/auto-trade` > ⚙️ 매매 기준 설정 맨 위 "전략 묶음"

판단에 맞춰 전략을 바꾸는 건 사람이 한다. 대신 버튼 한 번으로 청산 값이 한꺼번에 바뀌도록 묶음 세 개를 뒀다.

| 묶음 | 짧은 손절 | 트레일링 전환 | 전환 후 허용 하락 | 익절 |
|---|---|---|---|---|
| 🟢 좋음 — 손절 여유 · 수익 길게 | -8% | +5% | 고점 대비 -10% | +30% |
| 🟡 애매 — 당일 상승률 · 거래대금 위주 | -3% | +4% | 고점 대비 -4% | +6% |
| 🔴 나쁨 — 빠른 손절 · 빠른 익절 | -2% | +3% | 고점 대비 -1.5% | +4% |

- 세 묶음 모두 **짧은 손절 · 긴 수익 모드**(`docs/auto-trade-tight-stop.md`)를 켜고 폭만 다르게 둔다. 이 모드는
  물타기와 되돌림 익절을 쓰지 않아서 "빠른 손절"이 물타기로 늘어지지 않는다. 되돌림 익절 · 회복형 물타기는 끈다.
- **바꾸지 않는 값**: 1종목당 매수금액, 동시 보유 수, 루프 주기, RSI 과매수 매도, 정밀 매수조건, 투입 상한.
- 애매 묶음의 "당일 상승률 · 거래대금 위주"는 매수 대상을 고르는 방식이라 설정 값으로 바꿀 수 없다.
  종목은 🏆 당일 순위 화면에서 골라 관심 등록 · 실거래 승인한다.
- **이미 보유 중인 종목은 산 시점의 청산 규칙을 유지한다.** 묶음을 적용하는 순간 보유 종목마다 적용 직전의
  청산 값이 고정되고(`paper_positions.exit_rule`, 표 상태 칸에 🔒 산 시점 규칙), 새 묶음은 그 뒤에 새로 사는
  종목부터 적용된다. 이미 고정된 종목은 묶음을 또 바꿔도 처음 규칙 그대로이고, 전량 매도되면 규칙도 사라진다.
  - 버튼 아래 **"보유 중인 종목에도 바로 적용"**을 체크하고 누르면 반대로 고정 규칙을 전부 풀어서 보유 종목도
    곧바로 새 묶음을 따른다(새 손절선보다 이미 깊이 빠진 종목은 다음 사이클에 팔린다 — 확인창에 경고).
  - 이렇게 바꾼 이유: 처음엔 적용 즉시 보유 종목에도 새 값이 걸렸다. 2026-09-24 좋음(당시 손절 -3%)을
    누르자 이전 설정(물타기 대기)으로 이미 -4.8%~-10.6%에 있던 세 종목과, 본전 아래로 내려온 한 종목이
    다음 사이클에 한꺼번에 팔렸다.
- 좋음 묶음의 손절은 처음 -3%였다가 -8%로 넓혔다 — "좋은 시장이면 손실을 좀 더 버틴다"(jin3, 2026-09-24).
- 적용 중인 묶음은 따로 저장하지 않고 현재 설정값과 비교해 알아낸다. 묶음 적용 뒤 값을 하나라도 손으로 바꾸면
  "직접 설정"으로 표시된다.
- 시장 판단 칸에 "적용 중인 전략 묶음"이 같이 뜨고, 판단과 다르면 판단에 맞는 묶음 적용 버튼이 나온다.
  판단이 바뀌어 가는 슬랙 알림에도 지금 적용 중인 묶음이 같이 적힌다.
- API: `GET /api/auto-trade/strategy-presets`(목록 + 적용 중인 묶음), `POST /api/auto-trade/strategy-presets/apply`
  (`{"preset": "good" | "neutral" | "bad", "include_held": false}`)
