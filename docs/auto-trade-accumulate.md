# 모아가기 (업비트 실거래)

상태: ✅ 구현 완료 · 기본 꺼짐

BTC·ETH처럼 오래 모아갈 코인을 등록해두면, **정밀 매수조건을 통과할 때** 정해둔 금액만큼 사고
**자동으로 팔지 않는다.** 설정과 현황은 `/auto-trade`의 "🪙 모아가기" 카드 한 곳에 있다.

## 동작

| 항목 | 일반 매매 | 모아가기 |
|---|---|---|
| 매수 대상 | 스크리닝 후보 ∩ 매매 대상 ∩ 실거래 승인 | 등록한 코인(스크리닝·승인 무관) |
| 매수 신호 | 스크리닝 신호 (+ 정밀조건 게이트) | 정밀조건 통과 자체 |
| 관찰 모드 | 켜면 정밀조건이 매수를 막지 않음 | 무관 — 조건 통과일 때만 삼 |
| 이미 보유 중 | 안 삼 | 또 삼(모아가기) |
| 매수 빈도 | 사이클마다 | 코인별 `interval_hours`(기본 24시간)에 1번 |
| 최대 동시보유 종목수 | 셈 | 안 셈 |
| 자동 매도(손절·익절·RSI·물타기) | 함 | **안 함** — 업비트에서 직접 매도 |

- 켜진 정밀조건이 하나도 없으면 사지 않는다. 검사 결과가 15분보다 오래됐으면(`condition-check-bot`이
  멈춤) 사지 않는다.
- 현금이 1회 매수 금액보다 적으면 건너뛴다. 1회 매수 금액은 업비트 최소 주문금액(5,000원) 이상.
- 매수 간격은 `trade_order_log`에서 사유가 `모아가기`로 시작하는 체결된 BUY의 마지막 시각으로 잰다.
- 실거래 실행 스위치가 켜져 있어야 산다(일반 매매와 같은 사이클 안에서 ③단계로 판단).

## 켜고 끌 때

- 켜면 등록 코인은 일반 매매에서 빠진다 — 실거래 표에서 사라지고, 이미 추적 중이던 보유분도 자동 매도하지 않는다.
- 끄면 다시 일반 종목과 똑같다. **실거래 승인까지 된 코인이면 모아둔 보유분 전체가 일반 손절·익절 대상이 된다.**
  모아둔 코인을 계속 지키려면 끄기 전에 그 코인의 실거래 승인을 해제할 것.

## 코드

- 판단: `app/core/trade_strategy.py`의 `evaluate_accumulation()` (순수 함수)
- 실행: `app/core/auto_trader.py`의 `run_trade_cycle()` ③단계, 일반 매매 제외 처리
- 검사 대상 추가: `app/core/entry_condition_checker.py`
- 설정: `trade_accumulate_settings` 테이블, `POST /api/auto-trade/accumulate/settings`
- 테스트: `python tests/test_accumulate.py`
