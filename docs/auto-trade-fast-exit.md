# 적극 손절 · 익절 코인 (fast exit)

> 상태: ✅ 구현 완료 · **기본 꺼짐** (2026-09-30) · 업비트 전용
> 코드: `app/core/trade_strategy.py`의 `_evaluate_fast_exit()` · 설정은 `/auto-trade` 화면의
> "⚙️ 매매 설정" 카드 > **적극 손절 · 익절 코인**

## 왜 만들었나

"지금 있는 형태는 그대로 두고, 몇몇 코인은 손절과 익절을 적극적으로 하고 싶다"는 요청에서 나왔다.
기존 청산 규칙(익절 +10%, 고점 대비 -5% 트레일링 손절, 손절 전에 물타기 대기)은 모든 코인에 똑같이
걸려서, 변동성이 큰 코인만 더 빨리 끊고 싶어도 전체 값을 바꿀 수밖에 없었다.

## 규칙

목록에 적은 코인은 매 사이클 **다른 모든 청산 판단보다 먼저** 평단 대비 수익률을 본다.

| 조건 | 동작 | 청산 사유 |
|---|---|---|
| 수익률 ≥ +`fast_exit_take_profit_pct` | 즉시 전량 매도 | `fast_take_profit` (적극 익절) |
| 수익률 ≤ -`fast_exit_stop_pct` | 즉시 전량 매도 | `fast_stop_loss` (적극 손절) |
| 그 사이 | **기존 규칙 그대로** 판단 | — |

- 연속 확인(`stop_loss_confirm_cycles`)과 물타기 대기를 하지 않는다. 적극적으로 끊는 게 목적이라서다.
- 선에 안 닿으면 기존 흐름(익절 · RSI · 되돌림 익절 · 트레일링 손절 · 짧은 손절 · 회복형)을 그대로 탄다.
  그래서 기존 규칙이 더 빨리 파는 상황(예: 고점 대비 -5% 트레일링)은 그대로 살아 있다. 이 기능은 "더
  일찍 파는 선"을 하나 더 얹을 뿐이다.
- 폭을 **0**으로 두면 그쪽은 쓰지 않는다. 예: 손절 0 / 익절 5 → 익절만 +5%로 당기고 손절은 기존대로.
- 전략 묶음을 바꾸기 전에 산 종목(🔒 산 시점 규칙)에도 적용된다. 코인별 설정이라 묶음과 별개다.
- **모아가기 코인은 목록에 있어도 팔지 않는다.** 봇이 모아가기 코인을 청산 판단에서 아예 빼기 때문이다
  (`docs/auto-trade-accumulate.md`).

## 설정

| 키 | 기본값 | 의미 |
|---|---|---|
| `fast_exit_enabled` | `false` | on/off |
| `fast_exit_tickers` | 빈 목록 | 대상 코인. 화면에는 `XRP, SOL`처럼 쓰면 `KRW-`를 붙여 저장 |
| `fast_exit_stop_pct` | `3.0` | 평단 대비 이 % 하락하면 즉시 손절(0=기존 규칙) |
| `fast_exit_take_profit_pct` | `5.0` | 평단 대비 이 % 상승하면 즉시 익절(0=기존 규칙) |

기본값 -3% / +5%는 기존 기본값(고점 대비 -5% + 물타기 -10% 대기, 익절 +10%)보다 좁게 잡았다.
저장하면 `trade_strategy_settings`(업비트 행)에 들어가고, 실행 중인 매매 프로세스가 다음 사이클부터 쓴다.
켜져 있으면 실거래 표 위에 한 줄 요약이, 대상 코인 이름 옆에 `⚡ -3% +5%` 라벨이 뜬다.
API: `POST /api/auto-trade/settings`에 위 네 키만 보내면 된다(부분 갱신).

성과 화면(`/auto-trade/performance`)은 `fast_take_profit` / `fast_stop_loss`를 따로 센다. 빨리 판 게
나았는지는 이 두 사유의 건수와 평균 손익으로 본다. 백테스트는 `--from-db`로 돌리면 저장된 설정이 반영된다.
