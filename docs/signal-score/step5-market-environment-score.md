# 5단계: 시장/업종 환경 점수 산출 함수

- 상태: 완료
- 날짜: 2026-07-10
- 관련 파일: `app/utils/db_manager.py`

## 작업 내용
`sector_index_daily`에 저장된 코스피/코스닥 지수(사실상 "업종지수"라는 이름이지만 실제로는 시장 전체 지수 — `SECTOR_NAMES = {'0001': '코스피', '1001': '코스닥', '2001': '코스피200'}`)를 이용해 0~15점의 시장 환경 점수를 계산.

### 점수 구성
- 종목이 속한 시장(코스피/코스닥) 지수의 당일 등락률이 양수 → **+10점**
- 5영업일 전 종가 대비 오늘 종가가 높으면(상승 추세) → **+5점**

### 신규 함수
- `_get_index_score(sector_code, date)` — 시장 지수 하나(코스피 또는 코스닥)의 점수 계산 (내부 헬퍼)
- `get_market_environment_score(code, date=None)` — 종목 하나의 시장 환경 점수. `stock_market_cap_daily`에서 해당 종목이 속한 시장 구분(`fid_input_iscd`)을 먼저 찾고, 그 시장의 지수 점수를 반환. 반환: `{code, market, date, index_change_rate, index_trend_up, score}`
- `get_market_environment_score_batch(date=None, fid_input_iscd="combined")` — 전 종목 일괄 계산. 같은 시장 종목은 지수 점수가 동일하므로 시장별로 한 번만 계산 후 매핑(성능 최적화)

## 검증 (실제 데이터로 확인)
- HPSP(403870, 코스닥) 2026-07-09: 코스닥 지수 당일 +1.15% → `score: 10` (5일 추세는 하락 중이라 추세 보너스는 없음)
- 삼성전자(005930, 코스피) 2026-07-08(시장 급락일, 코스피 -5.35%): `score: 0` — 시장이 나쁘면 종목 상태와 무관하게 환경 점수가 낮게 나오는 것 확인
- 코스닥 종목 배치 조회 시 삼천당제약·HLB·주성엔지니어링 등 모두 동일하게 `score: 10` — 같은 시장이면 점수 공유하는 설계가 의도대로 동작

## 참고: 07-09 코스피 데이터 누락 이슈와의 관계
삼성전자(005930)로 `date='2026-07-09'` 조회 시 `market: None, score: 0`이 나오는데, 이는 지난 대화에서 확인한 **07-09 코스피(0001) 시총 데이터 누락 버그**의 영향임 — `get_market_environment_score`가 종목의 시장 구분을 `stock_market_cap_daily`에서 찾는데 그 날짜의 0001 데이터 자체가 없기 때문. 함수는 에러 없이 `None`/`0`으로 안전하게 처리함을 확인.

반면 `sector_index_daily`(지수 자체)는 별도 수집 경로(18/19시 배치)라 07-09 코스피/코스닥 모두 정상 존재함 — 이 버그는 시총 순위 수집에만 국한됨.

**버그 수정은 사용자 요청에 따라 별도 브랜치에서 나중에 진행하기로 함.**
