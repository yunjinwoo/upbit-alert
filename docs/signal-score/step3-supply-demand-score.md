# 3단계: 수급 점수(외국인/기관 N일 누적 순매수) 산출 함수

- 상태: 완료
- 날짜: 2026-07-10
- 관련 파일: `app/utils/db_manager.py`

## 작업 내용
`stock_investor_daily`에 이미 쌓여있는 외국인/기관 순매수 금액을 최근 N일(기본 3일) 누적해서 -15~30점의 수급 점수를 계산.

### 점수표 (`_score_supply_demand(frgn_total, orgn_total)`)

| 조건 | 점수 |
|---|---|
| 외국인·기관 3일 누적 순매수 모두 양수 (동반 순매수) | +30 |
| 둘 중 하나만 양수 | +15 |
| 둘 다 0 (데이터 없음/변화 없음) | 0 |
| 외국인·기관 모두 순매도 (동반 이탈) | -15 |

### 신규 함수
- `get_supply_demand_score(code, days=3)` — 종목 하나 계산. 반환: `{code, date_from, date_to, frgn_total, orgn_total, days_used, score}`
- `get_supply_demand_score_batch(days=3)` — `stock_investor_daily`에 데이터가 있는 전 종목 일괄 계산, 점수 내림차순 정렬

## 검증 (실제 데이터로 확인)
투자자매매동향은 이미 68개 종목(시총 상위 종목) × 최근 영업일 기준으로 쌓여있어 실제 데이터로 바로 검증함 (2026-07-06~07-08, 3일 누적).

- 동반 순매수 → 30점: 현대차(005380), 기아(000270), 현대모비스(012330), LG전자(066570), NAVER(035420), 삼성생명(032830)
- 동반 순매도 → -15점: 주성엔지니어링(036930), HPSP(403870), 펩트론(087010), 보로노이(310210)

수치도 이치에 맞음 — 예: 기아는 외국인 +47,132백만원 · 기관 +87,567백만원으로 강한 동반 순매수, 주성엔지니어링은 외국인 -9,281 · 기관 -22,918로 동반 이탈.

## 참고
- `stock_investor_daily`는 시총 상위 종목만 수집되므로(전체 상장 종목 아님) 이 점수는 그 범위 내에서만 계산됨 — 9번(전종목 확대) 작업과 연결됨.
- 3번(수급)과 4번(랭킹 안정성)은 순서가 뒤바뀌어 진행됨 — 4번을 3번보다 먼저 완료함. 결과에는 영향 없음.
