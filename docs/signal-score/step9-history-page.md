## 배경
7단계(종합 Signal Score 통합)까지는 등급 판정 로직만 있었고, 계산 결과를 저장하는 `signal_score_daily` 테이블과
조회 함수(`get_signal_score_history`)는 8단계 이후 세션에서 추가됐지만 정작 이 데이터를 보여주는 화면이 없어서
"매일 계산은 되는데 지나간 날짜 기록을 확인할 방법이 없는" 상태였음. 사용자가 "Signal Score의 이력을 관리하고 싶다"고
요청해서 이 공백을 메움.

## 1. 점수식 확장 (8~9단계 사이에 누적된 변경)

`progress.md`의 7단계 문서 작성 이후 별도 세션들에서 점수식 자체가 여러 번 바뀌었는데 문서화가 안 되어 있었어서 정리:

- **리스크패널티**: "최근 5영업일 +30% 이상 과열 → -15점" 조건을 "최근 **7**영업일 +30% 이상 **강한 상승 추세 → +15점**"으로
  전환(추격매수 경계 → 추세지속 베팅). 범위 -20~0점 → **-20~15점**(상한 없음, 하한 -20 유지).
- **HTS조회상위가점** 신설(0~10점) → 이후 0~20점으로 상향(1~3위=20/4~10위=12/11위 이하=6).
- **관심종목등록가점** 신설(0~10점, 1~3위=10/4~10위=6/11위 이하=3) — KIS `top-interest-stock` API 기반
  (네이버 인기검색종목이 `robots.txt`로 크롤링 금지라 대체 지표로 채택).
- 위 두 가점을 합쳐 **"관심도 보너스" 최대 30점** (`min(hts_bonus + top_interest_bonus, 30)`).
- 총점 = 기본점수(모멘텀+수급+랭킹안정성+시장환경+리스크패널티, 최대 105점) + 관심도 보너스(최대 30점).
  등급 기준(A 80↑/B 65~79/C 50~64/제외 50미만)은 변경하지 않음.
- `signal_score_daily` 테이블에 `hts_top_view_bonus_score`, `top_interest_bonus_score` 컬럼 추가(마이그레이션 포함).

## 2. Signal Score 이력 페이지 (`/signal-score-history`)

두 가지 보기를 탭으로 전환하는 단일 페이지로 구현:

- **일별 스냅샷**: 날짜(+등급 필터) 하나를 골라 `signal_score_daily`에 저장된 그날 전체 종목 점수/등급을 표로 조회.
  `get_signal_score_history(date, grade, limit)` — 기존에 만들어져 있었지만 아무 화면에서도 안 쓰이던 함수를 처음 연결함.
- **날짜별 추이**: 시작일~종료일 구간에서 종목별 총점을 날짜별 열로 펼친 매트릭스. HTS조회상위/관심종목등록 상위 페이지와
  동일한 UX(스티키 컬럼, 가로 스크롤, 종목명 검색)를 재사용. 신규 함수 `get_signal_score_range(date_from, date_to)`.
- 저장된 데이터는 최종 점수/등급까지만 있고 모멘텀 배수·수급 금액 같은 근거(detail)는 저장 안 하므로,
  상세보기 모달은 이 페이지에서는 지원하지 않음(실시간 근거가 필요하면 `/signal-score-preview`의 상세보기 이용).

## 검증
- 실제 저장된 이력 데이터(2026-07-14~07-20)로 두 탭 모두 확인 — 일별 스냅샷 60건, 날짜별 추이 64개 종목 정상 표시.
- 관심도 보너스 30점 상한: DB 복사본에서 HTS 20점 + 관심종목등록 10점 = 30점(상한 그대로, 초과 없음) 확인.
  실제 라이브 데이터로도 삼성전자/SK하이닉스가 30점 상한 적용된 총점 85점(A등급)으로 계산되는 것 확인.
- 리스크패널티 부호 전환 후 실제 7일 급등 종목(+15점)과 5일/7일 계산 차이(과거 5일 기준 과열이었던 종목이 7일 기준으로는
  기준 미달로 빠지는 경우)를 DB 조회로 재현/확인.
